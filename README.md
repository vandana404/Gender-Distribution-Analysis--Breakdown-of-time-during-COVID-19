# Time Distribution Around the Clock

## Project Overview
This project analyzes how people in India distributed their time across various daily activities during the COVID-19 lockdown. The study explores patterns related to work, education, household responsibilities, leisure activities, sleep, and social interactions.

## Dataset
The dataset contains information from 100 respondents across different Indian states. Each record includes:

- Name
- State
- Gender
- Age
- Paid Work (Minutes)
- Education (Minutes)
- Care for Household Members (Minutes)
- Housework (Minutes)
- Shopping (Minutes)
- Sleep (Minutes)
- Personal Care (Minutes)
- Sports and Yoga (Minutes)
- TV and Internet (Minutes)
- Other Leisure Activities (Minutes)

## Key Findings

- Sleep was the most time-consuming activity during lockdown.
- Attending events was the least common activity.
- Females spent more time on household work compared to males.
- Males spent more time on leisure activities.
- Teenagers allocated the highest amount of time to education.
- Outdoor activities were significantly reduced during lockdown.
